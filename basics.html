How the plan works

This section is self-contained. Labels: E means the prescription follows directly from the research above. I means it is a coaching inference or convention built on that research.

How to read the prescriptions

TermMeaning
RPE / RIR
RPE 10 = 0 reps in reserve (RIR); RPE 9 = 1 RIR; RPE 8 = 2 RIR; RPE 7 = 3 RIR; RPE 6 = 4 RIR
Top set
The heaviest set of the day for a main lift, done after warm-ups
Backoff sets
Lighter sets done after the top set at the stated % of training max
TM (training max)
~90% of current estimated 1RM, used to calculate loads I
e1RM
Estimated 1RM = load × (1 + reps/30) (Epley formula; a convention, not a validated individual predictor) I
Double progression
For accessories: when every set reaches the top of the rep range at the target RIR, add the smallest available load next session I
Tempo
Controlled 1–3 s lowering, fast intentional lift on all exercises E

Progression and autoregulation rules

SituationRule
Top set is ≥1 RPE above target
Do backoffs 5% lighter and repeat that week's load next week. Two misses in a row on the same lift: drop TM 5% I
Top set is ≥1.5 RPE below target
Add an extra 5 lb (upper) or 10 lb (lower) to next week's top set I
Accessory hits top of rep range on all sets at target RIR
Add the smallest increment next session (double progression) I
Accessory reps drop two sessions in a row
Hold the load and check sleep and food before cutting volume I
Early-deload triggers
Joint pain that persists past warm-ups, or two consecutive sessions with main lifts ≥1 RPE harder at the same load. Take the week-6 deload early [I, matching triggers reported in E]
Failure
Only on the last set of machine, cable or isolation work. Never deliberately on barbell squat, bench, deadlift or OHP outside testing EI

Exercise substitution rules

Keep the four barbell main lifts (back squat, bench, conventional deadlift, standing OHP) fixed for all 12 weeks, because free-weight strength is specific to free-weight practice E. Accessories may change only at a block boundary, or immediately if an exercise causes pain. A replacement must train the same muscle in the same rep range for the same number of sets, and should preferably load the muscle in a stretched position I. If you want to try sumo deadlifts because of your long frame, test them in the next cycle, not mid-block I.

Warm-up

Do 5 minutes of easy general cardio, then progressive ramp sets of the main lift (e.g. bar, 40%, 55%, 70%, 80% of the top-set load). Limit static stretching before lifting to ≤45 s per muscle, because longer pre-lift stretching cuts force by ~5% (Simic 2013) E. Do longer mobility or flexibility work after training or on Sunday (Thomas 2023) E.
